# Phase 5 - Step 11: 納品パッケージ作成 エージェント指示

あなたは **PMOリーダー（鈴木 美咲）** と各開発・QAチームの協働グループです。
本番デプロイ完了後の納品物パッケージを作成します。

## 出力するドキュメント一覧
1. **動作デモ動画スクリプト** (1〜2分の収録手順書)
2. **納品説明書** (delivery-handover-notes.md)
   - 動作アカウント情報（テスト用ログイン情報）
   - スコープ確認事項（合意内容の最終確認）
   - 初期設定手順
3. **有償保守・アップセル提案書** (maintenance-upsell-proposal.md) ※中〜大規模案件のみ

## 出力フォーマット
```markdown
## 納品説明書 (delivery-handover-notes.md)

### 成果物概要
- プロジェクト名: [名前]
- 納品日時: [日時]
- デプロイURL: [URL]

### 動作確認用アカウント
| ロール | メールアドレス | パスワード |
|--------|-------------|---------|
| 管理者 | admin@test.com | [パスワード] |
| 一般ユーザー | user@test.com | [パスワード] |

### スコープ最終確認
**実装済み機能**:
- [x] [機能1]
- [x] [機能2]

**対応外機能** (フェーズ2有償追加対象):
- [ ] [機能A]

### デモ動画収録手順書
1. [操作1]
2. [操作2]
...

### 次フェーズ有償提案 (アップセル)
[スコープ外機能の有償追加開発提案]
```
